## Developmental ownership decision

`FloraIndividual` already stores authoritative `Id`, `SpeciesId`, `Age` (sim seconds), `Biomass`, `Health`, `LifespanFactor` and serialized `ClimberSegments` (their own age/parent index). Render-only leaf emergence thresholds may be computed from stable axis ancestry + local node index + whole-plant `Age`; never derive stage from fluctuating `BiomassFraction`. A regenerated organ retains stable shape seed from `plant Id + biological axis path + organ slot`, independent of mesh tessellation and plant-instance visibility. For real stochastic injury/regrowth, ecology must eventually own minimal live node age/death state; no event log.

## Baseline architecture defects found

`MeshData.RecordLeaf` derives identity from `Leaves.Count` (traversal order); `FloraRenderer` batches whole-specimen 3-tier morph variants in `MultiMesh`, and `Juvenile` is a per-plant alternative. Thus neither per-leaf maturity nor cross-stage static shape persistence is presently implemented. Do not call infrastructure-only changes a conversion.
