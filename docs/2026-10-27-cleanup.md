## Effect sweep

Use `scripts/visuals/benchmark.ps1` with the existing environment controls instead of the removed one-off `scripts/run_effect_sweep.py`. In PowerShell, preserve and restore caller environment values:

```powershell
$oldSweep = $env:VIVARIUM_BENCHMARK_EFFECT_SWEEP
$oldKind = $env:VIVARIUM_BENCHMARK_SWEEP_KIND
try {
    $env:VIVARIUM_BENCHMARK_EFFECT_SWEEP = '1'
    $env:VIVARIUM_BENCHMARK_SWEEP_KIND = 'all'
    ./scripts/visuals/benchmark.ps1 -Scenario frozen -ConfirmIsolation
} finally {
    $env:VIVARIUM_BENCHMARK_EFFECT_SWEEP = $oldSweep
    $env:VIVARIUM_BENCHMARK_SWEEP_KIND = $oldKind
}
```

The benchmark runner checks GPU isolation and captures provenance. It does not terminate other applications. Use an explicitly supplied world path when comparing a specific world.
