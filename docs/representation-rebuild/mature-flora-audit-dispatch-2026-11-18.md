## Rules for every agent

1. Audit first: read the species' Finding/Correction, view the overnight after-captures (and macros
   where the finding demands detail), then read the recipe code. Verdict per species:
   VERIFIED (finding answered), ADJUSTED (targeted edit made), GAP (needs shared support or owner
   judgement), or PRESERVED (accepted form; inspect-only).
2. Targeted edits only. Never revert or rewrite the overnight baseline wholesale. Preserve accepted
   silhouettes — Moonbark and Shiverleaf are inspect-only except demonstrable junction/base gaps.
3. No new bioluminescence; existing emission (Tidebell bells, Starmoss uprights, Glowbriar) preserved.
   No richness reduction for performance; flag cost risks instead of thinning (Banksorrow ~536k tris
   LOD0, Sootband ~1k axes, Raincup ~2x organs, Mirespire tube needles are known hot spots).
4. Deterministic seeded variation only; stable across seeds/ages/LODs. Keep taper/attachment
   continuity contracts (catalog validation checks them).
5. No `dotnet build`, no Godot runs, no git stage/commit/reset/clean/checkout. The orchestrator
   integrates, builds, tests and renders serially (one GPU window).
6. Do not touch unrelated dirty files (legacy Geometry, `.import` metadata, `project.godot`, saves).
7. Report: `artifacts/mature-flora-audit-2026-11-18/<batch>.md`, one row per species with verdict,
   evidence viewed, edits (file/method), residual risk. Final chat reply <= 15 lines.

## Priority checks carried over from the review handoff

- Hollowcrown: grown-over curled rim + merged limb junctions still open; opening must face catalog camera.
- Witchberry: burls too rounded, root flare, fan-leaf center-tip notch unsupported.
- Cloudtuft: must read as cloudy cotton/milkweed mass, not smooth pods with sparse fibers.
- Cragparasol: deep-blue spikes must be visible at whole-plant distance; no mid-trunk stairstep.
- Coalspike: sheathing laminae are not true encircling tubular sheaths.
- Blackneedle: black spines may float/bury at the blade join (macro check).
- Carrion Bell: species-specific rib branch — check angularity at reduced LODs.
- Climbers: supported/fallback continuation can progressively clamp segment radii at parent attachments.
- Widowspire: finest terminal tip can be culled at LOD 2 by the thin-twig rule.
- Emberfan: derived production attachment can go stale on paused direct host mutation.
- Moss/lichen mats: verify live-coverage path, not only standalone specimen (extraction selects a
  shoot subtree; root-sibling understory is excluded by design).
