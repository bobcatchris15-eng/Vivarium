This probe is an initial-population run (flora 110 / fauna 134 at end), not the mature-island save referenced in `docs/perf-overhaul-baseline.md` (4.9 FPS, ~9.7 M primitives), so the two are not directly comparable; use this document as the "before" baseline for subsequent overhaul comparisons by rerunning the same command and diffing `perf_report.json`.
