# Visual lab bounded runner

Integrated runner. Invoke `pwsh -NoProfile -File E:/Vivarium/scripts/visual-lab/VisualLab.ps1 -Command initialize -Experiment foliage-01 -Repo E:/Vivarium`. The wrapper locates the repository by walking upward to scripts/verify.ps1 when -Repo is omitted, so it works from this worker directory or an integrated scripts location.

Commands: initialize, baseline, status, inventory, capture, blind, compare, decision, resume, halt, unhalt; authored and critiqued record handoffs. Resume executes baseline, blind, or compare when ready, otherwise returns an explicit capture, author, critique, or decision next_action. It never schedules work or contacts APIs.

Typical sequence:

1. initialize; baseline (or resume). Baseline copies all eligible Git-tracked and untracked game/src/config files, including assets, retaining paths, hashes, revision and dirty status. Credentials and build/cache paths are excluded. Interrupted baseline is retained and fails integrity checks.
2. capture -Side before -ConfirmIsolation. Capture current baseline before author edits. Wrapper acquires exclusive FileStream .clanker/visual-lab-gpu.lease and checks both HALTs again after leasing. Existing Godot/Vivarium/Blender processes block capture. No unrelated processes are stopped.
3. Author edits through separately authorized work; authored -AuthorIdentity author-worker-id.
4. capture -Side after -ConfirmIsolation; blind. Default capture calls the same --reference machinery used by scripts/verify.ps1 with an explicit experiment output directory. Optional -Mode material-port-review calls the actual-game fixture. Add -GeometryOnly for single captures when comparing source geometry. -Diagnostic permits explicitly labelled captures alongside competing renderers; it never establishes isolated performance. Capture records exit, actual screenshots, shader-error screening, source hash, and baseline manifest hash. It scopes and restores VIVARIUM_LANDSCAPE_SCENARIO and VIVARIUM_BENCHMARK_USER_DIR; user settings/saves live in capture/user. Run necessary build/import separately before capture, as this wrapper does not build.
5. Independent critic reviews critic/index.html without private/mapping.json, writes critic/critique.json, then critiqued; compare delegates to scripts/compare-reference.ps1. Full reference captures retain the existing comparator and report validation. PNG-only material fixtures use a matched static gallery with image hashes, explicitly no performance or aesthetic verdict. Mixed/missing report formats still fail through the original comparator.
6. decision -Decision accept|reject|revise. Accept additionally needs independent critic_identity distinct from recorded author_identity, at least three nonempty observed_defects, verdict accept, blind_manifest_sha256 matching critic/manifest.json, motion_reviewed true, motion_file relative to experiment with supported video/GIF extension and motion_sha256. Captures must show successful actual render, before must authenticate protected baseline. performance/render_report.json must pass the existing scripts/visuals/validate-report.py and match candidate capture source hash. Obtain real benchmark evidence separately with scripts/visuals/benchmark.ps1; preserve its full run directory contents under performance. No pass is synthesized.

JSON hashes authenticate evidence integrity, not reviewer identity against a trusted identity provider. Human/operator must assign independent critic and protect private mapping. Motion presence/hash/format is verified; critique attests actual review. File paths reject traversal and existing Windows junction/reparse components. These checks are cooperative filesystem safeguards, not protection against a hostile concurrent process replacing paths after checks.

HALT stops mutations/work; status, halt, unhalt remain available. Experiment unhalt never removes global .clanker/HALT. Exclusive lease is held only during capture and released in finally. Capture timeout stops only its own spawned process through scripts/common.ps1 Invoke-Timed. Failed captures remain for diagnosis; existing evidence directories cannot silently be overwritten. State JSON uses fsync and atomic replacement; use one operator for each experiment (state writes are not a multiwriter transaction protocol).

Run `python test_visual_lab.py` for standard-library tests. test-output.txt contains the original 10-test result (11 tests now pass after adding the matched fixture gallery guard), including Windows junction rejection, FileStream exclusivity, halt handling, atomic state, missing evidence rejection, source tampering, independent critique, and concrete resume. The integrated runner subsequently executed protected source snapshots and actual renderer captures. No candidate performance acceptance has passed.

The integrated -Mode world-review uses a disposable real initial GameSession and existing reference camera queries, high quality 1600x900 and light phase420. It pauses the world before starting and captures55 views; successful runs check unchanged paused-world digest. It is a diagnostic photograph mode, without six-day warmup, performance measurements or save/load replay acceptance. Engine time pauses after startup; exact initial shader TIME remains unmeasured. Keep full --reference and landscape gates for acceptance. The source/asset manifest and camera/seed/tick/count/digest checks authenticate matched evidence, not identical global shader phase.
