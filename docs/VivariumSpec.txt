# Digital Desktop Vivarium

plan vivarium-first-draft
summary Build a complete first-draft Digital Desktop Vivarium as a native standalone offline-capable Windows application. This is not a prototype. Implement the complete agreed feature families, initial content libraries, persistence, packaging, deterministic simulation, diagnostics, and acceptance coverage.
